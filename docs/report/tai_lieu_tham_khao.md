# Tài liệu tham khảo {.unnumbered}

1. A. Waterman, K. Asanović (eds.), *The RISC-V Instruction Set Manual, Volume I: Unprivileged ISA*, RISC-V International.
2. A. Waterman, K. Asanović, J. Hauser (eds.), *The RISC-V Instruction Set Manual, Volume II: Privileged Architecture*, RISC-V International.
3. D. A. Patterson, J. L. Hennessy, *Computer Organization and Design RISC-V Edition: The Hardware/Software Interface*, Morgan Kaufmann.
4. J. L. Hennessy, D. A. Patterson, *Computer Architecture: A Quantitative Approach*, 6th ed., Morgan Kaufmann (chương về pipeline và dự đoán rẽ nhánh).
5. ARM, *AMBA APB Protocol Specification* (APB4), ARM IHI 0024.
6. Winbond, *W25Q32JV – 3V 32M-bit Serial Flash Memory with Dual/Quad SPI*, datasheet.
7. RISC-V International, *riscv-tests*, https://github.com/riscv-software-src/riscv-tests (commit `3df703c`).
8. RISC-V International, *Spike RISC-V ISA Simulator*, https://github.com/riscv-software-src/riscv-isa-sim (commit `436fc16`).
9. W. Snyder et al., *Verilator*, https://verilator.org (phiên bản 5.047).
10. C. Wolf et al., *Yosys Open SYnthesis Suite* (0.63) và *nextpnr* (ECP5), YosysHQ.
11. EEMBC, *CoreMark*, https://github.com/eembc/coremark (commit `1f483d5`).
12. R. P. Weicker, *Dhrystone: A Synthetic Systems Programming Benchmark*, Communications of the ACM, 1984 (bản trong riscv-tests/benchmarks).
13. lowRISC, *Ibex RISC-V Core Documentation*; C. Wolf, *PicoRV32* – dùng để so sánh kiến trúc.
